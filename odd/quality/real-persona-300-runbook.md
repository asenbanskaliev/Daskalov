# Evaluación de personalidad real, con cuotas y datos sintéticos

`npm run eval:persona:remote` permite 1–300 llamadas secuenciales contra el modelo elegido. Solo se envía el dataset versionado y artificial de `scripts/persona-eval-cases.mjs`; nunca se recuperan conversaciones de alumnos ni grabaciones. El operador configura `DASKALOV_REMOTE_EVAL_CONSENT=1`, `DASKALOV_REMOTE_EVAL_PROVIDER=nvidia`, `DASKALOV_REMOTE_EVAL_MODEL=<modelo-del-catálogo>`, `DASKALOV_REMOTE_EVAL_LIMIT=20` (o hasta 300 con presupuesto aprobado) y `NVIDIA_API_KEY` en un entorno seguro (para OpenRouter usar `OPENROUTER_API_KEY`). Nunca almacenar claves en el repo.

Salida: `reports/remote-persona-live.json` contiene el modelo, versión del dataset, número de llamadas **realmente realizadas**, IDs fallidos y contadores, sin respuestas ni prompts. El proceso se detiene en el primer error de proveedor y no reintenta automáticamente (cuotas/costes). Los casos se valoran con heurísticas limitadas; un docente y un experto de seguridad infantil deben validar su calidad antes de aprobar S08.06 o cualquier release. No subir el informe bruto si el propietario no lo ha revisado. Sin un modelo operativo en NVIDIA, el script no puede completar las 300 solicitudes.
